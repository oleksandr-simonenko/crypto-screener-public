# Версии закреплены ТОЧНО (==), а не диапазоном (>=), намеренно.
# Причина: GitHub Actions ставит зависимости строго отсюда и на КАЖДОМ прогоне
# заново. При `>=` любой новый релиз requests или PyYAML попадает в воркфлоу
# молча — и расхождение чисел между двумя прогонами одного и того же кода
# невозможно отличить от изменения данных. Вердикт 15.11.2026 обязан быть
# воспроизводим: один git_sha -> одно окружение -> одни числа.
# Обновление версии — отдельное осознанное действие с прогоном тестов,
# а не побочный эффект чужого релиза.
#
# Версии проверены на PyPI 01.09.2026 (актуальные релизы на эту дату).
# Больше в проекте не используется ничего: numpy/scipy/pandas ЗАПРЕЩЕНЫ,
# вся статистика считается на stdlib.
